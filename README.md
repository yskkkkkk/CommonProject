# Persona

한 계정으로 여러 개의 **캐릭터(페르소나)** 를 만들어, 그 페르소나로 게시·소통하는 SNS 서비스입니다.
일반적인 SNS와 달리 사용자의 원래 정체성이 아니라 상황·관심사별로 만든 캐릭터 단위로 활동합니다.

> 학기 팀 프로젝트로 진행했습니다 (5인, 2022-01-03 ~ 2022-02-18).

## 역할 분담

| 구분 | 담당 |
|---|---|
| 팀원 1 | Back & Front |
| 팀원 2 | Back |
| 팀원 3 | **Back & Server** (서버·인프라 구성 단독 담당) |
| 팀원 4 | Front |

## 기술 스택

**Backend**
- Java, Spring Boot, MyBatis, MySQL
- JWT 인증, Spring Mail(이메일 인증), Swagger(springfox)

**Frontend**
- React 17, React Router
- Tailwind CSS, Material Tailwind, Headless UI

## 주요 기능

### 회원 · 인증
- 회원가입 / 로그인(JWT)
- 아이디 찾기 · 비밀번호 찾기 (이메일 기반)
- 계정 설정 — 비밀번호 · 생년월일 변경 (아이디 · 이메일은 변경 불가)

### 캐릭터(페르소나)
- 캐릭터 생성 / 수정 / 삭제, 닉네임 중복 확인, 카테고리
- 캐릭터 선택·전환 (한 계정의 여러 페르소나 사이 전환)
- 마이페이지 · 프로필 편집
- 팔로우 / 팔로워 목록, 다른 캐릭터 프로필 조회

### 콘텐츠(피드)
- 게시물 작성 / 수정 / 삭제 — 공개·비공개 설정, 태그 추가, 파일 다중 업로드
- 메인 피드 · 개인(캐릭터) 피드, 태그 피드
- 좋아요 (게시물 · 댓글)
- 댓글 작성 / 삭제 / 좋아요
- 게시물 · 댓글 신고 (사유 선택 + 내용 작성)

### 보관함(Storage)
- 저장목록(컬렉션) 생성 — 이름 · 공개여부 설정
- 게시물을 저장목록에 저장 / 해제
- 저장소 내부 게시글 목록, 저장소 삭제

### 업적(Achievement)
- 완료한 업적 모아보기
- 대표 업적 설정 / 해제

### 검색(Search)
- 검색어 히스토리 기반 추천
- 실시간 인기 검색어 순위
- 결과를 캐릭터 · 태그 · 내용 · 저장소별로 분류하여 제공

### 알림(Alarm)
- 게시물 추가 · 댓글 · 저장소 생성/변경 · 업적 달성 알림
- 알림 유형별로 해당 페이지로 이동, 유형별 On/Off 설정

## 프로젝트 구조

```
backend/    Spring Boot + MyBatis REST API
frontend/   React 웹 클라이언트
docs/       설계 문서 — API 명세서, 화면정의서
exec/       DB 스키마(DDL) · 초기 데이터(DML), 시연 시나리오 등 배포·발표 자료
```

## 실행 · 배포

- DB는 `exec/persona_ddl.sql`(스키마)과 `exec/persona_dml.sql`(초기 데이터)로 구성합니다.
- 애플리케이션 설정 예시는 `exec/application.properties.png`를 참고하세요.
- 화면 흐름·기능 시연은 `exec/Persona_시연_시나리오.docx`에 상세히 정리되어 있습니다.

## 참고

- 애플리케이션 설정(`backend/src/main/resources/application.properties`)에 하드코딩된 자격증명이 남아 있어, 별도의 보안 정리(자격증명 폐기·환경변수 이전)가 필요합니다.
